# PHOTO-LOG

사진을 찍고 기록을 남기는 안드로이드 앱. 서버 없이 모든 데이터가 폰 안에 저장된다.

## 저장 위치
- 사진: 앱 전용 저장 공간. 갤러리·Google 포토·파일 앱에 보이지 않는다. 앱을 지우면 함께 지워지므로 백업을 이용한다.
- 백업: 목록 화면 오른쪽 위 ⋮ → 백업 내보내기 / 불러오기. 사진과 기록을 zip 파일 하나로 저장해 Google 드라이브 등에 보관하거나 새 폰으로 옮긴다.
- 메모·위치·날짜: 앱 내부 저장소의 `entries.json`. 앱을 지우면 함께 지워진다.

## 기능
- 시작 화면: 연 → 월 → 일 아코디언 메뉴 + 날짜별 3열 사진 그리드
- 사진 추가: 카메라로 찍기 / 갤러리 / Google 포토. 여러 장을 한 번에 고를 수 있고, 원본을 앱 안으로 복사한다.
- 날짜 스탬프: 필름카메라 날짜 각인처럼 주황 7세그먼트 숫자
- 촬영 위치 자동 기록: 사진의 EXIF GPS를 읽는다. 카메라로 찍었는데 사진에 위치가 없으면 촬영 직후 폰 위치(15분 이내)로 보완한다.
- 사진 꾹 누르기: 그리드에서 사진을 길게 누르면 공유·삭제 메뉴
- 상세 화면: 사진 + 날짜 스탬프, 위치(지도에서 보기), 기록 입력·저장, ⋯ 메뉴의 삭제
- 공유: 크기 조절해서 공유(원본·1:1·4:5·9:16 비율, 확대·이동으로 보낼 부분 선택, 형식: 사진만 / 사진 위에 기록 / 사진 + 기록 카드, 기록을 글로 함께 보내기, 날짜 넣기 — 날짜는 항상 사진 우측 하단 고정, 기록은 최대 5줄 입력) / 원본 그대로 / 기록 복사. 안드로이드 공유 메뉴로 인스타그램·카카오톡·메시지에 바로 보낸다.

## 디자인
- 색: 기본 모드는 흰색, 다크 모드는 검정. 강조색은 날짜 스탬프 주황 하나.
- 앱 아이콘: 기본 모드 흰 바탕에 검정 PHOTO-LOG, 다크 모드 검정 바탕에 흰 글씨(`values-night`). 안드로이드 13 이상의 테마 아이콘도 지원.
- 글꼴: 제목 Playfair Display Italic, 사이드바·날짜 고운바탕, 메모는 폰의 시스템 글꼴(삼성 글꼴 스타일 등 그대로 적용). 모두 SIL Open Font License.
- 사이드바: 왼쪽 위 메뉴 버튼으로 숨기기/보이기. 숨기면 그리드가 4열로 넓어지고, 상태는 다음 실행에도 유지된다.

## 빌드와 설치
1. 이 저장소를 GitHub에 올리면 Actions가 APK를 빌드한다(`.github/workflows/build.yml`).
2. Actions 탭 → 최근 실행 → Artifacts의 `photo-log-apk`를 내려받아 압축을 푼다.
3. 폰에서 `app-release.apk`를 열어 설치한다(출처를 알 수 없는 앱 허용 필요).

서명 키는 저장소에 없다. GitHub Secrets의 `SIGNING_KEYSTORE_B64`(키 파일 base64, 길면 앞부분과 뒷부분을 `SIGNING_KEYSTORE_B64`·`SIGNING_KEYSTORE_B64_2`로 나눠 등록 가능)와 `SIGNING_PASSWORD`로 빌드할 때마다 같은 키로 서명하므로, 새 빌드를 앱 삭제 없이 덮어 설치할 수 있다. 저장소를 포크해 직접 빌드하려면 자신의 키를 같은 이름의 Secrets로 등록한다.

## 처음 실행 시 권한
- 사진 위치 정보 접근: 사진 속 위치를 지우지 않고 읽기
- 위치: 카메라가 위치를 넣지 않은 사진의 보완용
- 사진 접근: 앨범 사진의 원본 읽기

거부해도 앱은 동작하며, 그 경우 위치가 기록되지 않을 수 있다. 카메라 앱 설정의 "위치 태그"를 켜 두면 가장 정확하다.

## 구성
- Kotlin + Jetpack Compose (Material 3), minSdk 29(안드로이드 10)
- `Entry.kt` 데이터·저장소, `PhotoStore.kt` 폴더 저장·EXIF, `Sharing.kt` 공유·카드, `Ui.kt` 화면
