### 데이터 보안

- 앱이 사용자 데이터를 수집하거나 공유하나요? → **아니요**
- 근거: Google Play 기준의 "수집"은 기기 밖으로 전송하는 것을 말한다. PHOTO-LOG는 인터넷 권한이 없고, 사진·기록·위치는 기기 안에만 저장한다. 공유·백업은 사용자가 직접 고른 곳으로 보내는 행위라 수집에 해당하지 않는다.
- 전송 중 암호화 / 삭제 요청 방법 항목은 "수집하지 않음"이면 묻지 않는다.

### 권한 사용 설명

| 권한 | 용도 |
|---|---|
| 위치(정확·대략, 앱 사용 중) | 앱 카메라로 찍은 사진에 위치 정보가 없을 때 촬영 장소를 기록 |
| 사진 위치 정보 접근(ACCESS_MEDIA_LOCATION) | 사용자가 고른 사진의 촬영 장소를 읽기 |

사진 전체 접근 권한(READ_MEDIA_IMAGES)과 카메라 권한은 요청하지 않는다. 사진은 시스템 선택 화면으로 고른 것만 가져오고, 촬영은 기기의 카메라 앱을 연다.

## 4. 출시 절차 (개인 계정)

1. Play Console 가입(25달러, 신원 확인, Play Console 앱으로 기기 인증)
2. 앱 만들기 → 위 정보 입력
3. 테스트 → 비공개 테스트 트랙 생성 → `PHOTO-LOG.aab` 업로드
4. 테스터 12명 이상의 Gmail을 등록하고 참여 링크 전달 → **14일 연속** 참여 유지
5. 대시보드에서 프로덕션 액세스 신청 → 승인 후 프로덕션 출시
